# Klasifikasi-Sentimen-Program-MBG-Algoritma-Machine-Learning
Platform komputasi analisis opini publik terhadap program Makan Bergizi Gratis (MBG) menggunakan arsitekturMulti-Class Soft-Voting Ensemble (Support Vector Machine, Multinomial Naive Bayes, dan Complement Naive Bayes)yang terintegrasi dengan pemetaan semantik dan deteksi negasi Bahasa Indonesia.
